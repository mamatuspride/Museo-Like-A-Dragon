# Museo-Like-A-Dragon
Benvenuti nel Museo Like A Dragon, dove si formano sogni e speranze.
Il Museo "Like a Dragon" è un sito web che parla della mia serie di videogiochi preferita, Yakuza (oggi conosciuta come Like a Dragon). Ci sono descrizioni dei giochi e le ambientazioni, alcuni pezzi delle colonne sonore, e dei video che dimostrano il gameplay. 

Non è per deboli di cuore.

Il contenuto potrebbe essere considerato troppo "epico" per alcuni spettatori. Si consiglia la visione ad un pubblico adulto.
